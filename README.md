## 📖 Descripción del Proyecto

Este repositorio contiene el código fuente de una aplicación web interactiva diseñada para realizar un Análisis Exploratorio de Datos (EDA) sobre un conjunto de datos de anuncios de ventas de automóviles en Estados Unidos. 

La herramienta está pensada para que cualquier usuario, sin necesidad de experiencia técnica previa, pueda explorar y extraer conclusiones iniciales sobre las tendencias del mercado automotriz de manera visual e intuitiva.

## ✨ Características

* **Interfaz Interactiva:** Controles amigables que permiten al usuario manipular las visualizaciones.
* **Visualización de Datos:** Gráficos dinámicos (histogramas, gráficos de dispersión, etc.) que facilitan la comprensión de las distribuciones y correlaciones de los datos.
* **Despliegue en la Nube:** Aplicación completamente funcional y accesible a través de Render.

## 🎓 Contexto

Este proyecto fue desarrollado como parte de los requisitos prácticos del bootcamp de Data Analytics de **TripleTen**. Su objetivo es demostrar el dominio en la creación de aplicaciones web para el análisis de datos utilizando Python y librerías modernas de visualización.
